## Reporting a Vulnerability

If you discover a security vulnerability within `jwt-security-analyzer`, please report it privately:

- **Email**: security@example.com
- **PGP Key**: Fingerprint `9B4C 3D2E 1F0A 8B7C 6D5E 4F3A 2B1C 0D9E 8F7A 6B5C`

Please include:
1. Detailed description of the potential vulnerability.
2. Steps to reproduce or proof-of-concept token.
3. Potential impact assessment.

We aim to respond to reports within 48 hours and coordinate remediation before public disclosure.
